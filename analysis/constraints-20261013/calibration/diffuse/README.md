# Bounded diffuse recalibration diagnostic

The regional survey discrepancy is real in the matched-map check, but **no physically acceptable global preset was selected** in this pass. `fit.json` contains a two-parameter exploratory *synchrotron amplitude/spectral tilt* fit; both parameters saturated their imposed bounds, so that preset is **rejected** and should not be wired into the production pipeline. The before/after plot is a sensitivity diagnostic only.

A second trial using only nonnegative volume-synchrotron and extragalactic amplitudes also hit the synchrotron lower bound (0.05) while leaving the held-out southern Orion 22-MHz longitude bins 24–36% high. A third two-amplitude trial, scaling volume synchrotron **and local radio shells together** plus the extragalactic component, had an interior optimum (0.421 and 0.864 respectively) and reduced held-out RMS log residual from 0.528 to 0.186, but left Orion 22 MHz 36–44% high and would cut literature-conditioned loop amplitudes by 58%. It is an experimental sensitivity point, not an accepted preset. The relevant component medians in that region are observed 22 MHz ≈20 kK, saved extragalactic component ≈23 kK, local shells ≈4 kK and volume synchrotron ≈18 kK. Therefore lowering only diffuse synchrotron cannot match that survey without changing a different physical component or its absolute calibration. This is not evidence that the extragalactic astrophysical spectrum is wrong: the 22-MHz survey has a possible several-kK zero-level error and declination gain tied to Haslam 408 MHz, while the model inherits survey information through ULSA tuning. Those systematic and lineage terms need resolution before physically retuning either component.

Use the [unfitted regional comparison](../../comparisons/radio_regions/README.md) as the result. Its southern 45-MHz sample uses only the Maipu part of the composite. The attempted split uses arithmetic **means** for survey and each model component in every bin, so the linear component recombination is exact. It holds out alternating longitude bins **within the same maps**, not an independent experiment; spatial scatter is not a measurement covariance. The saved model has fixed thermal opacity and shells, and no parameter derived here was applied to it.
